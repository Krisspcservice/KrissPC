KRISSPC — responsywna strona gotowa do publikacji

PLIKI
- index.html — cała strona (HTML + CSS + JavaScript).
- assets/logo.png — tutaj dodaj własne logo (opcjonalnie).
- assets/podglad-projektu.jpg — podgląd projektu, nie jest używany jako cała strona.

JAK DODAĆ LOGO
1. Przygotuj logo PNG (najlepiej z przezroczystym tłem; kwadratowe).
2. Skopiuj je do folderu assets i nazwij dokładnie: logo.png
3. Jeśli nazwa będzie inna, zmień ścieżkę w index.html w tagu <img id="siteLogo" src="assets/logo.png">.
4. Jeśli nie dodasz logo, nazwa KRISSPC nadal będzie widoczna.

JAK OBEJRZEĆ
Rozpakuj ZIP i otwórz index.html w przeglądarce. Mapa Google wymaga internetu.

JAK OPUBLIKOWAĆ ZA DARMO (PRZYKŁAD: GITHUB PAGES)
1. Zaloguj się lub utwórz konto na GitHub.
2. Utwórz nowe publiczne repozytorium, np. krisspc.
3. Prześlij index.html oraz cały folder assets (z zachowaniem struktury).
4. Wejdź w Settings -> Pages.
5. W sekcji Build and deployment wybierz Deploy from a branch, następnie branch main i folder /(root), po czym Save.
6. Po publikacji GitHub pokaże adres strony. Pierwsze uruchomienie może potrwać kilka minut.
7. Po każdej zmianie plików prześlij ich nowszą wersję do repozytorium; strona zaktualizuje się po chwili.

WAŻNE
- Wgrywaj index.html i folder assets razem.
- Nie zmieniaj nazw folderu ani plików, jeśli nie aktualizujesz ścieżek w HTML.
- Przed publikacją sprawdź telefon, e-mail i adres na mapie. Mapa jest osadzona z Google Maps i wymaga połączenia z internetem.
- Sprawdź, czy masz prawo publikować podane dane kontaktowe/adres.
